# Task 3 – Image and Button Styling

## 📌 Project Description
This project demonstrates basic HTML and CSS styling. It displays an image with a button placed directly below it. CSS is used to control the layout, spacing, image dimensions, and button appearance.

## 🛠️ Technologies Used
- **HTML5** – To create the webpage structure.
- **CSS3** – To style the webpage elements.

## ✨ Features
- Displays an image using the HTML `<img>` tag.
- Places a button below the image.
- Uses CSS padding to control spacing around the content.
- Makes the image and button occupy the full available width of their container.
- Applies a linear gradient background to the button using yellow and green colors.
- Uses `display: block` to position the image properly.

## 📂 Project Structure

```text
Task-3/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run
1. Download or clone this project.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in any web browser.
4. The webpage will display the image and the styled button.

## 🎯 Learning Outcomes
- Understanding HTML image and button elements.
- Linking an external CSS stylesheet.
- Using CSS selectors and properties.
- Understanding padding and element positioning.
- Applying linear gradients using CSS.
